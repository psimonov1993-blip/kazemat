# Штаб Каземата в Telegram

Сайт сам публикует в канал каждое изменение доски и каждую новую версию игры. Здесь: как подключить канал и бота, если они когда-нибудь поменяются, и как проверить, что всё работает

## Что уже подключено (1 ноября 2026)

- Канал https://t.me/masterskayagames, название «Мастерская ИГРы. Каземат»
- Бот @kazematbot - администратор канала с правом публиковать сообщения
- Секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` заданы в репозитории psimonov1993-blip/kazemat
- На сайте канал включён: кнопка в первом экране, раздел «Штаб в Telegram», кнопка «Канал» в нижней панели на телефоне

Повторять шаги ниже не нужно. Они пригодятся, если канал или бот сменятся

## 1. Создать канал

1. В Telegram: карандаш или «Новое сообщение» → «Создать канал»
2. Название и описание - любые, их видят подписчики
3. Тип канала - **публичный**, придумать короткую ссылку, например `kazemat`. Только у публичного канала работает лента новостей на сайте

## 2. Создать бота

1. Открыть @BotFather, отправить `/newbot`
2. Ввести имя бота (видно людям) и логин, который заканчивается на `bot`
3. BotFather пришлёт токен вида `123456789:AA...`. Это пароль от бота: кто его знает, тот пишет в канал от имени бота

## 3. Сделать бота администратором

1. Канал → Управление каналом → Администраторы → Добавить администратора
2. Найти бота по логину
3. Оставить включённым право «Публикация сообщений», остальное можно выключить → Сохранить

## 4. Что прислать Claude

- ссылку на канал, например `https://t.me/kazemat`
- токен бота

Токен присылай только лично, в рабочий чат с Claude. Не публикуй его в канале и общих чатах и не сохраняй в файлах проекта: он хранится только в секретах GitHub

## 5. Положить токен в секреты

```
gh secret set TELEGRAM_BOT_TOKEN -R psimonov1993-blip/kazemat
gh secret set TELEGRAM_CHAT_ID -R psimonov1993-blip/kazemat --body "@kazemat"
```

Первая команда спросит значение: вставь токен и нажми Enter. Так токен не попадёт в историю команд. Во второй вместо `@kazemat` - логин своего канала с собачкой

## 6. Включить канал на сайте

```
python tools/board.py telegram set --url https://t.me/kazemat --name "Название канала"
```

Команда впишет канал в `board.json` и опубликует сайт. Выключить: `python tools/board.py telegram clear`

## 7. Проверить

```
gh workflow run telegram.yml -R psimonov1993-blip/kazemat -f mode=selftest
gh workflow run telegram.yml -R psimonov1993-blip/kazemat -f mode=dry-run
gh run list -R psimonov1993-blip/kazemat --workflow telegram.yml --limit 3
gh run view <номер из списка> -R psimonov1993-blip/kazemat --log
```

- `selftest` отправляет в канал тихое сообщение без звука и сразу его удаляет. В логе будет его номер и «Удаление ... успешно»
- `dry-run` ничего не отправляет, печатает в лог готовые посты по последнему изменению доски и по последнему релизу
- `admintest` отправляет проверочную копию последнего изменения доски только в личку взрослому организатору, в канал ничего не уходит
- `hello` (по желанию) публикует приветственный пост канала: что сюда приходит и ссылку на сайт

## Что публикуется само

| Что случилось | Откуда | Пост |
|---|---|---|
| В гарнизон добавлен боец | `board.py member add` | позывной, звание, сколько приказов, сколько мест свободно |
| Боец сменил звание | `board.py member rank` | новое звание и сколько приказов в запасе |
| Поступил приказ | `board.py order add` | номер, позывной, тип, где, суть (у пасхалок суть скрыта), статус |
| Приказ принят, в игре, возвращён | `board.py order status` | номер и живая строка про изменение |
| Изменилось число мест, цена или приказы звания, открыт новый сезон | `board.py season seats`, `rank set` | новые условия |
| Опубликован релиз на GitHub | `gh release create` | версия, список изменений из описания релиза, позывные авторов приказов этой версии, обложка и кнопка на сайт |

Посты приходят подписчикам со звуком. После отправки номера постов попадают в `news.json`, и сайт показывает последние четыре в разделе «Штаб в Telegram»

Позывные авторов в посте о релизе берутся из доски: приказы со статусом «в игре» и той же версией, что у релиза (`order status --n 3 --status done --version 1.1` и релиз с тегом `v1.1`)

## Копия взрослому организатору

Необязательный секрет `TELEGRAM_ADMIN_CHAT_ID`: если он задан, бот присылает в личку подробную копию каждого изменения доски (новый боец, приказ с полным текстом, даже у пасхалок, смена статуса, любые другие правки `board.json`) и каждого поста о релизе

1. Взрослый открывает бота @kazematbot и нажимает «Start». Без этого бот не может написать ему первым
2. Узнать свой числовой id: например, написать боту @userinfobot, он ответит числом
3. Положить id в секрет:

```
gh secret set TELEGRAM_ADMIN_CHAT_ID -R psimonov1993-blip/kazemat --body "123456789"
```

Нет секрета - копия молча не отправляется. Если копия не дошла, публикация в канале всё равно проходит, причина видна в логе запуска

## Кому уходят приказы с сайта

Кнопка «Отправить организатору» под приказом открывает чат с ником из `board.json` → `organizer.telegram` и подставляет текст приказа. Сменить или убрать:

```
python tools/board.py organizer set --telegram ник_без_собачки
python tools/board.py organizer clear
```

Без организатора вместо этой кнопки показывается «Поделиться в Telegram»: участник сам выбирает, кому переслать приказ

## Если пост не пришёл

```
gh run list -R psimonov1993-blip/kazemat --workflow telegram.yml --limit 5
gh run view <номер> -R psimonov1993-blip/kazemat --log
```

- «секреты не заданы, публикация пропущена» - нет `TELEGRAM_BOT_TOKEN` или `TELEGRAM_CHAT_ID`, шаг 5
- «chat not found» или «not enough rights» - бот не администратор канала или в `TELEGRAM_CHAT_ID` опечатка, шаги 3 и 5
- «Unauthorized» - токен отозван. В @BotFather: `/mybots` → бот → API Token → Revoke, новый токен снова через шаг 5
